# Oficina Virtual — Demo

Prototipo estático para revisar pantallas y navegación. Todos los datos precargados son ficticios. No procesa trámites, declaraciones ni pagos reales.

## Publicar
En Settings > Pages, elegir Deploy from a branch, main y /(root), y guardar.

## Desarrollo
Abrir con un servidor HTTP local. Ejecutar npm test para validar el flujo de agentes.
