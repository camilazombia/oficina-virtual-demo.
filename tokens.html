Tokens de color del proyecto

Colores utilizados por los estilos y componentes presentes en el proyecto actual, incluida su guía visual. Se muestra el tema claro activo, con nombres sugeridos para Figma, valores y muestras de color.

01 Primitives

Colores base reutilizados por el proyecto. Ejemplo: --bs-blue.

02 Semantic

Expresan una intención: acción principal, éxito, texto o superficie. Pueden cambiar según el tema. Ejemplo: --bs-body-color.

03 Components

Colores locales de botones, tarjetas, menús y sus estados. Ejemplo: --bs-btn-bg.

Clasificación de documentación basada en el alcance y la intención de las variables existentes. Bootstrap no declara formalmente estos tres niveles; se conservan sus nombres y valores originales.

Cómo llevar esta estructura a Figma

Crea las colecciones 01 Primitives, 02 Semantic y 03 Components. Dentro de cada colección, usa el nombre sugerido: las barras / representan grupos anidados. Los nombres son una propuesta para este proyecto.

En Semantic y Components, usa modos Light y Dark para los valores de tema de una misma variable. Los estados y variantes de componentes se conservan en la ruta; no son modos de tema. Conecta los componentes a variables semánticas y estas a primitivas mediante alias del mismo tipo.

El valor mostrado sigue siendo CSS: convierte unidades como rem a números antes de crear variables numéricas. Los valores var(...) deben convertirse en alias. Las sombras y las composiciones tipográficas se documentan como estilos de efecto y de texto; las ternas RGB son auxiliares del código, no colores independientes para importar directamente.
